# Digital Warranty Manager

A simple web mini-project for storing product warranty details, tracking expiry dates, searching/filtering products, and viewing summary statistics.

## Run
1. Install Node.js 18+.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open http://localhost:3000

## Features
- Add, edit, delete warranties
- Warranty status: Active / Expiring Soon / Expired
- Search and category filtering
- Dashboard statistics
- Local browser persistence with localStorage
- Responsive UI
